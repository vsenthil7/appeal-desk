How to use it

  1. Install
    From the sub's mod toolbar, install Appeal-Desk on your subreddit. The app needs Reddit moderator scope, Redis, and the scheduler. No external HTTP.
  2. Mod action triggers an invite
    When you ban or remove content, the user receives a civil modmail inviting them to file a structured appeal. The original action context is snapshotted at the moment of action — the user can't edit your reason.
  3. Triage from the dashboard
    Use the "Appeal-Desk: create dashboard" menu item once per sub to pin the appeals queue. Each appeal opens with full history, a near-duplicate Jaccard flag, and three one-tap buttons: Uphold, Overturn, Ask for more info.
  4. Reply-confirm gate
    Every one-tap button opens a reply-confirm form with a templated civil reply pre-filled. Nothing is sent until you confirm. The decision is recorded before the reply is dispatched.
  5. Audit trail + retention
    Every decision, reply, and state change is logged. A daily retention purge runs at 03:00; GDPR-style erasure is available from the mod menu (scrubs free text, keeps a tombstone, idempotent).

Structured intake

Validated, sanitised, rate-limited. Per-action atomic lock (WATCH/MULTI/EXEC CAS) prevents duplicate appeals.

Deterministic dedup

Jaccard fingerprint against the user's prior appeals — surfaced as a flag, never as a block.

AI is optional

NoopAiProvider is the default. Toggle on in settings; the full happy path works either way.

Platform-free core

core/ + ai/ import nothing from Devvit. 100% function coverage without the runtime.
