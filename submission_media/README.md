# Appeal-Desk \u2014 Submission media

This folder is the **single source of truth** for everything the AT-Hack0022
submission needs the judges to see, beyond the repo itself.

## Contents

| File | What it is | Generated by |
|---|---|---|
| `appeal-desk-pitch-deck-<stamp>.pptx` | 12-slide editable deck | `scripts/build_pitch_deck.py` |
| `appeal-desk-pitch-deck-<stamp>.pdf`  | 12-slide deck (print)  | `scripts/pptx_to_pdf.ps1` (PowerPoint COM) |
| `cover-square-1200x1200.png`           | App Directory thumbnail | `scripts/build_cover_image.py` |
| `cover-banner-1600x900.png`            | 16:9 hero banner        | `scripts/build_cover_image.py` |
| `cover-og-1200x630.png`                | Open Graph / Twitter    | `scripts/build_cover_image.py` |
| `JUDGE_TEST_SCRIPT.md`                 | Deterministic walkthrough (source) | written by hand |
| `JUDGE_TEST_SCRIPT.pdf`                | Same, branded PDF       | `scripts/build_judge_script_pdf.py` |
| `SUBMISSION_FORM.md`                   | Copy-paste reference for the hackathon submission form | written by hand |
| `README.md`                            | This file               | \u2014 |

The `assets/icon.png` (512x512) lives at the repo root \u2014 it's the Devvit app
icon, not a submission-portal asset.

## How to regenerate everything

From the repo root:

```
# 1. Covers + icon (Pillow)
python scripts/build_cover_image.py

# 2. Pitch deck (python-pptx -> pptx)
python scripts/build_pitch_deck.py

# 3. Convert deck to PDF (PowerPoint COM)
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/pptx_to_pdf.ps1

# 4. Judge test script PDF (reportlab)
python scripts/build_judge_script_pdf.py
```

A backup of each PPTX + PDF is also written to `submission_media/_backup/`
on every generation, so a rebuild never loses the previous artefact.

## What is *not* in this folder

- The **App Directory listing** itself \u2014 lives at
  https://developers.reddit.com/apps/appeal-desk and is the canonical "this is
  installable today" link in the submission form.
- The **playtest sub** \u2014 `r/appeal_desk_dev`, auto-created by `devvit upload`.
- The **demo video** \u2014 recorded against the live playtest sub. Generated by a
  separate pipeline (`scripts/record_demo.ps1` + Playwright); see the
  `demovideo/` folder if/when it ships.

## Verification

The judge test script gives every claim a concrete pass criterion (number of
tests, coverage thresholds, behavioural assertions you can replicate on the
live install). If a number quoted in the deck or `SUBMISSION_FORM.md` doesn't
match the script's pass criteria, the script wins \u2014 it's the script that runs
against the actual repo.
